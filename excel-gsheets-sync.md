Разработай Python-проект для двусторонней синхронизации между Google Sheets и Excel.


Необходимые библиотеки храни в .venv (virtual environments)

## ТЕХНОЛОГИИ:
- Python 3.10+
- gspread (для Google Sheets)
- openpyxl (для Excel)
- google-auth
- python-dotenv

## ФУНКЦИОНАЛ:
- Авторизация через сервисный аккаунт Google (creds.json)
- Чтение таблицы по ID из .env (SPREADSHEET_ID)
- Чтение листа по названию из .env (SHEET_NAME)
- Два режима работы (выбор через аргумент командной строки):

### Режим 1: --export (Google Sheets → Excel)
- Читает данные из Google Sheets
- Создаёт Excel-файл с именем report_YYYYMMDD_HHMMSS.xlsx
- Применяет форматирование:
  * Заголовки: жирный шрифт, серая заливка, границы
  * Данные: выравнивание (текст - влево, числа - вправо)
  * Автоширина колонок по содержимому
  * Условное форматирование: если значение в любой числовой колонке > 100, ячейка зелёная

### Режим 2: --import --file "путь_к_файлу.xlsx" (Excel → Google Sheets)
- Читает данные из указанного Excel-файла
- Обновляет содержимое листа в Google Sheets (заменяет все данные, сохраняя заголовки)
- Проверяет, что первая строка (заголовки) совпадает по структуре (количество колонок)
